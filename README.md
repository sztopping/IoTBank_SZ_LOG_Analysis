# IoTBank_SZ_LOG_Analysis · Log 分析工具

各机型测试日志解析与分析上位机（WPF / .NET 8），提取设备识别码与固定信息，对返回参数做自适应统计分析，生成可交互的 HTML 报告（内嵌 ECharts、中日英三语）。

## 功能特性

- **日志导入**：拖拽导入单个/多个同类型日志文件或整个文件夹（自动递归）。
- **机型自动识别**：内置 B203 / B504 / B509ES / B705/B706 / 音频 B903 五个解析器，按文件名 + 内容特征双重判型，插件化可扩展。
- **唯一识别码**：以 IMEI（含 Luhn 校验）→ MAC → SN 优先级链提取；自动识别「IMEI 字段存 12 位十六进制」时归为 MAC（B705 场景）。
- **设备对比**：勾选单个/多个设备号进行对比分析（多设备箱线图等）。
- **自适应统计引擎**：描述性统计、相关分析（Pearson）、时间序列趋势、多设备分布对比；KANO / SEM / 中介效应按数据形态自适应触发。
- **交互图表**：拖动缩放（dataZoom）、十字虚线指示（axisPointer）、悬浮数据高亮（tooltip）、图表上方标题、坐标轴名称+单位（Y 轴纵向）。
- **中日英三语**：一键切换，图表标题/坐标轴/指标名/结论全部随语言切换。
- **离线报告**：单文件 HTML，内嵌 ECharts，可双击打开、可分享。

## 支持的机型

| 机型 | 识别码 | 主要时序参数 |
|---|---|---|
| B203 | IMEI | LTE/WiFi/BLE/ESP32 RSSI |
| B504 | IMEI | 温湿度、震动/看门狗计数 |
| B509ES | IMEI | 电池电压 |
| B705/B706 | MAC | BLE/WiFi RSSI |
| 音频 B903 | IMEI | THD、SNR、底噪、灵敏度 |

## 构建与发布

```bash
# 开发构建
dotnet build

# 发布自包含单文件 exe（拷贝到任意 Win10+ 电脑直接运行，无需安装 .NET 运行时）
./publish.ps1
```

发布产物：`publish/LogAnalyzer_{版本}.exe`（自包含 + 单文件），随附 `docs/` 操作说明与全代码文档。

## 目录结构

```
LogAnalyzer/
├─ Models/        数据模型（设备档案 + 三语文案/图表规范）
├─ Parsers/       解析器插件（机型识别 + 识别码提取链）
├─ Analysis/      自适应统计引擎
│   └─ Methods/   描述统计/相关/趋势/箱线图/KANO/SEM
├─ Report/        HTML 报告生成（内嵌 ECharts）
├─ Services/      日志导入服务
├─ ChangeLog.cs   版本变更记录
└─ docs/          操作说明 SOP + 全代码全功能说明
```
