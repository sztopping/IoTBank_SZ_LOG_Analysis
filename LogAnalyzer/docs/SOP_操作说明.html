Log 分析工具 · 操作说明 (SOP)

版本 V0.1.2 · 适用于各机型日志（B203 / B504 / B509ES / B705/B706 / 音频 B903）及未知机型（智能解析 / AI 增强）

一、工具简介

本工具用于解析各机型（B203 / B504 / B509ES / B705/B706 / 音频 B903 等）测试上位机导出的日志文件，自动提取设备唯一识别码与固定信息，对返回参数进行科学统计分析与图表可视化，并生成可交互的 HTML 分析报告（支持中日英三语切换）。

核心能力

  • 导入单个/多个同类型日志文件，或整个文件夹（自动递归）。
  • 以唯一识别码（IMEI / MAC / SN）为准，提取设备固定信息。
  • 指定单个/多个设备号进行对比分析（多设备箱线图等）。
  • 精准解析返回参数，自动匹配适用统计方法（描述统计 / 相关 / 趋势 / 箱线图对比等）。
  • 智能解析：对未预定义的新机型，读入日志后自动探测时间戳格式、识别「字段=数值+单位」模式、区分固定信息与时序指标、自动推断单位。
  • 交互图表：拖动缩放、十字虚线指示、悬浮数据高亮、Y 轴纵向名称、图表上方标题。
  • 中日英三语一键切换。
  • 单文件便携：发布版为自包含单文件 exe，拷贝到任意 Win10+ 电脑直接运行，无需安装 .NET 运行时。

二、运行环境

项目要求
操作系统Windows 10 / 11（64 位）
运行时无需安装（发布版已自包含 .NET 8 运行时）
浏览器内核WebView2 Runtime（Win10/11 通常已内置；缺失时报告预览区会显示占位文本，导出 HTML 不受影响）
网络核心功能（解析/统计/报告）均离线可用；启动时会检测联网并提示
依赖无外部依赖，报告离线可用

三、操作步骤

1
导入日志

三种方式任选：

  • 直接把 .txt / .log 文件或文件夹拖入窗口；
  • 点击菜单「文件 → 选择日志文件...」多选文件；
  • 点击菜单「文件 → 选择日志文件夹...」选择文件夹（自动递归子目录）。

导入后左侧显示设备列表（机型 + 识别码 + 指标/字段数）。

2
选择要分析的设备

在左侧设备列表勾选一台或多台设备（默认全选）。勾选多台时将生成设备间对比分析。

3
生成分析报告

点击底部「生成分析报告」按钮，右侧预览区即显示 HTML 报告。

4
查看与交互
  • 顶部「中文 / 日本語 / English」按钮切换报告语言（图表标题、坐标轴、指标名、结论全部随语言切换）。
  • 图表支持滚轮/拖动缩放（右下滑块或框内拖动）；
  • 鼠标悬停显示十字虚线，悬浮弹窗高亮对应数据点；
  • 坐标轴显示名称与单位，Y 轴名称纵向显示。
5
导出报告

点击「导出 HTML 报告」按钮，选择保存路径，即可得到可分享的单文件离线报告。

四、支持机型与识别码

机型日志格式特征识别码主要参数
B203[时间][RX/TX/SYS] AT 指令IMEILTE/WiFi/BLE/ESP32 RSSI、MAC、ICCID、SW/HW
B504>> [时间] 调试数据IMEI温湿度、震动/看门狗计数、Fs.* 配置
B509ES00> [时间]<inf> 固件日志IMEI电池电压、SW/SDK/OS、UniqueID、Gsensor
B705/B706时间戳 [INFO] 上位机日志MAC（IMEI 字段存 hex）BLE/WiFi RSSI、SW/HW、MAC
音频 B903$Test Start / 判定行IMEITHD、SNR、底噪、灵敏度
识别码提取优先级：IMEI（含 Luhn 校验）→ MAC → SN。某些机型把 MAC 以 12 位十六进制写进「IMEI:」字段（如 B705），工具会自动识别为 MAC 类型。

五、解析优先级模式（本地优先 + AI 增强）

工具的解析采用本地优先、联网增强、离线降级三级策略：

优先级条件行为
① 本地解析预定义机型（B203 等）或智能解析器可完整解析直接本地解析，不联网
② 联网 AI 增强本地解析不完整 + 电脑联网 + 已配置 AI 密钥自动调用免费 AI 工具（DeepSeek/Kimi/智谱GLM 等）增强解析
③ 离线降级本地解析不完整 + 电脑未联网弹窗提示「仅输出本地解析报告」，不再尝试联网

如何启用 AI 增强解析（可选）

编辑程序目录下的 ai_config.json，在对应提供商的 apiKey 填入密钥（DeepSeek / Kimi / 智谱GLM 均有免费额度，注册后获取）。可配置多个提供商，工具会依次尝试，首个成功即返回。

未配置任何密钥时，工具完全离线运行，AI 增强自动跳过（不影响本地解析）。

六、统计方法说明

工具采用自适应统计引擎：每个统计方法自带适用性判断，按日志实际数据形态自动决定调用哪些方法，避免「硬套方法得出无意义结论」。

方法触发条件输出
描述性统计任一指标有数据均值/中位数/标准差/极值/变异系数表 + 时序折线图
相关分析单设备 ≥2 个指标（各 ≥3 点）Pearson 相关系数矩阵 + 强相关组合结论
时间序列趋势指标 ≥10 点线性回归斜率/R² + 趋势判定 + 趋势图
多设备箱线图≥2 台设备有同名指标boxplot 分布对比
KANO / SEM / 中介数据含问卷/量表形态时log 客观参数默认不触发

八、常见问题

Q1：报告预览区空白？

可能是本机未安装 WebView2 Runtime。可安装「Microsoft Edge WebView2 Runtime」后重启，或直接点击「导出 HTML 报告」用浏览器打开（导出不受影响）。

Q2：某些设备未被识别？

确认文件名/内容符合上表特征；若为未支持的新机型，需新增对应解析器插件。

Q3：报告体积较大？

因内嵌 ECharts 图表引擎（约 1MB）+ 完整数据，属正常现象，换取完全离线可用。
